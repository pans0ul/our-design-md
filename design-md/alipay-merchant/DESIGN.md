# DESIGN.md — 支付宝商户（Alipay Merchant）

**来源 URL**：https://b.alipay.com/page/portal/home  
**采集范围**：支付宝商家平台首页单页；桌面视口 1280×800，另在移动视口 360×732（Playwright mobile 模式）下验证同一文档未自适应；未登录状态；页面标题「首页 - 商家平台」；`document.documentElement.lang` 为空字符串。  
**采集日期**：2026-09-30  
**证据环境**：Playwright Headless Chromium（playwright-cli 0.1.22），macOS；辅助脚本 `bin/capture-site.sh` 生成 `/tmp/alipay-merchant/desktop.json` 中的 24 个 DOM samples、29 个 type-scale 条目、27 个 CSS 变量、以及手工 `eval` 抽取的 header/banner/card/footer/input/login 组件数据。

## Overview

- **视觉气质**：单一主色「蚂蚁蓝 `#005BF8`」+ 极浅灰页面底色 `#F5F5F5` 的克制金融 SaaS 风格；Hero 使用饱和深蓝色块 `#004BC8` + 半透明白色按钮营造活动位；卡片族用 24px 大圆角 + 双层浅蓝阴影（`rgba(138, 159, 194, 0.106) 0 10px 20px 0, rgba(215, 224, 239, 0.596) 0 7px 15px 0`）区分层次；整体走 Ant Design 5 + 自研 `--portal-*` / `--cem-*` 设计 token 混合路线。
- **目标用户 / 场景**：面向商家与开发者的门户首页；顶部 6 大入口（首页 / 接入指引 / 产品大全 / 文档中心 / 解决方案 / 规则中心 / 服务市场）+ 搜索 + 「注册企业支付宝」+ 「登录」；Hero 轮播 6 张活动 banner（Antom 出海收单、AI 支付开发者激励、AI 行业解决方案、芝麻租赁、碰一下、点餐立减）；中部「丰富的收款工具」按场景列出 4 个入口卡（淘宝等平台收款 / 线下场所收款 / 网站 APP 收款 / 小程序收款），底部引导企业支付宝注册与 400 客服热线；页脚提供新手入门 / 服务支持 / 移动端小程序入口。
- **信息密度**：桌面文档 1280×4645，主要区块从上到下为「蓝色顶栏 60px → 蓝色 Hero 轮播 446px → 4 卡工具列表（含一个 540×520 Hero + 三个 204×520 标签）→ 企业支付宝注册 CTA → 页脚 464px」。桌面密度中等，卡片内 40px 顶部 padding + 32px 左侧 padding；未登录态下无用户个性化内容，仅展示营销文案与 CTA。
- **设计关键词**：蚂蚁蓝、大圆角卡片、浅蓝阴影、蓝色 Hero 轮播、PingFang SC、Ant Design。

## Typography

### 3.1 中文字体与字形

- **简体中文**：`body` 的 computed `font-family` 为 `"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif`；全站绝大多数中文文本（导航、卡片、注册 CTA、页脚说明）使用此栈。
- **繁体中文**：本次采集的公开首页未观察到繁体切换入口或繁体文案，不推断繁体字形策略。
- **实际渲染字体**：本次环境为 Playwright Headless Chromium on macOS；`PingFang SC` 在 macOS 上会命中系统字体；Windows 上预期回退至 `Microsoft YaHei`（栈第 2 位），Linux 上预期回退至 `sans-serif` 默认（栈未声明 Noto Sans CJK 显式兜底）。未通过字体枚举验证最终字形命中情况。
- **缺字回退**：未验证。栈末为通用 `sans-serif`；页面无 `Noto Sans CJK` / `Source Han Sans SC` 等跨平台中文字体声明。
- **页脚专用栈**：页脚 `.footerBox___Qpedp` 独立使用 `Tahoma, arial, "Hiragino Sans GB", "Microsoft Yahei"`，此栈首位是拉丁字体 `Tahoma`，中文回退路径为 Hiragino Sans GB → Microsoft Yahei，与主内容栈不同；这是历史遗留的支付宝集团统一页脚样式。

### 3.2 西文字体

- **无衬线（主内容）**：由 `PingFang SC` 承担中文与英文（英文在 PingFang SC 上直接使用其 Latin 字形）；西文 fallback 依次为 `Microsoft YaHei`、`Helvetica Neue`、`Helvetica`、`Arial`。
- **无衬线（Hero / Ant 组件）**：Hero 轮播与 Ant Design 组件族（按钮、输入框、`banner-item`）使用 `-apple-system, "system-ui", "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"`；这是 Ant Design 5 的默认栈，把系统字体放到首位，中文回退到 `Noto Sans`（Linux）或系统默认。
- **无衬线（页脚）**：`Tahoma` 承担拉丁字母，中文回退 `Hiragino Sans GB` → `Microsoft Yahei`。

## Do's and Don'ts

- **Do** 使用 `#005BF8` 作为主品牌色 / 主 CTA 底色 / 登录按钮 / 激活链接 / Logo 色；CSS 变量 `--portal-active-color`、`--portal-header-active-color`、`--portal-menu-active-color`、`--portal-logo-color` 全部指向同一值。
- **Do** 使用 `#004BC8` 深蓝色仅作为 Hero 轮播背景；不要把它当作品牌主色，也不要把主色 `#005BF8` 用作 Hero 底色。
- **Do** 使用双层浅蓝阴影 `rgba(138, 159, 194, 0.106) 0 10px 20px 0, rgba(215, 224, 239, 0.596) 0 7px 15px 0` 作为卡片阴影；这是站点唯一的大面积卡片阴影。
- **Do** 使用主 CTA 装饰阴影 `rgba(5, 145, 255, 0.1) 0 2px 0 0` 给按钮制造按压感；卡片「立即注册」与 Ant `.ant-btn-primary` 共享同一阴影 token。
- **Do** 使用 6px / 24px / 28px / 100px / 24px（卡片）5 档圆角分工：6px 给 Ant 输入框，24px 给卡片与 Ant 主按钮，28px 给 Hero 半透明按钮与卡片 CTA，100px 给顶部登录胶囊。
- **Do** 保留三种字体栈的并存：主内容用 `PingFang SC` 栈，Hero + Ant 组件用 `-apple-system` 栈，页脚用 `Tahoma` 栈；不要统一替换为单一栈。
- **Do** 保留 Ant Design 默认 line-height 1.571429 的精确值（25.1429px、21px、22px）；不要取整。
- **Do** 使用 `#36373D` 作为卡片主标与输入框的次级文本色；与 `#333333` 主文本色区分。
- **Do** 使用 `#8B8EA0`（浅蓝灰）作为分区副标；`#657792`（深靛蓝灰）作为页脚分组标题；`#666666` 作为非激活卡片主标。三档灰各有语义。
- **Do** 保留 Hero「了解更多」半透明玻璃按钮的 `rgba(255, 255, 255, 0.1)` 底 + `rgba(255, 255, 255, 0.2)` 描边组合；不要替换为纯白或纯透明。
- **Do** 记录 `document.documentElement.lang` 实测为空字符串，在 preview 与 index.json 中如实填写。
- **Don't** 把 Hero 深蓝 `#004BC8` 当作品牌主色 `#005BF8` 的替代；两者颜色相差约 10 度亮度，分别用于「活动位大色块」与「主 CTA / 链接 / Logo」，语义不同。
- **Don't** 把 CSS 变量 `--cem-primary-color: 22, 119, 255`（约 `#1677FF`）当作品牌主色；它是 Ant Design 5 默认的备用主色，页面组件实际使用的是 `#005BF8`。
- **Don't** 给顶部导航或页脚添加 `box-shadow`；两者均 `box-shadow: none`。
- **Don't** 用 `word-break: break-all`、`line-break: strict`、`text-wrap: balance` 或 `letter-spacing` 调优作为中文字体默认优化；页面 computed 全部为 `auto / normal / normal`。
- **Don't** 声明页面支持移动响应式；实测移动视口下文档宽度仍为 1280px，横向溢出约 920px，站点通过页脚提示把移动用户引导至支付宝商家助手小程序。
- **Don't** 把 Hero 上的中文（如「Antom 助企业出海」）断言为使用 `PingFang SC` 渲染；该元素的 computed 栈首位是 `-apple-system`，中文实际走系统 fallback 或 `Noto Sans`。
- **Accessibility**：Playwright 快照显示顶部导航、Hero「了解更多」按钮、卡片「立即注册」CTA 与页脚链接均可被浏览器读取；未做键盘遍历、对比度或触控目标尺寸验证。`#005BF8` 白字对比度约 4.88:1（通过 WCAG AA 4.5:1 门槛）；`#8B8EA0` 副标在 `#F5F5F5` 底上约 2.7:1（低于 AA 门槛，但属于分区副标的可接受弱化设计）；`rgba(255, 255, 255, 0.1)` Hero 按钮半透明底在 `#004BC8` 上的对比度依赖底图渐变，未做逐像素验证。
