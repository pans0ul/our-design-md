# DESIGN.md — 商汤科技 SenseTime

**来源 URL**：https://www.sensetime.com/cn/  
**采集范围**：商汤科技中文官网首页单页；桌面 1280×720，另检查移动视口 390×844；未登录状态；页面标题「商汤科技 SenseTime」。  
**采集日期**：2026-09-30  
**证据环境**：Playwright Headless Chromium（playwright-cli），macOS。

## Overview

- **视觉气质**：暖白（`#fbfaf7`）作为整站底色，黑、深靛（`#111827`）和商汤红（`#f02e27`）三档文本色形成克制的层级；玻璃质感头部（`rgba(255,255,255,0.28)` + `blur(34px)`）与 20px 圆角卡片贯穿首屏，形成偏品牌官网的编辑风格而非产品控制台。
- **目标用户 / 场景**：面向公众的品牌官网，展示日日新大模型体系、SenseCore 大装置、SenseFoundry 视觉 AI 等产品线索；同时提供新闻动态、技术专题与「产品咨询」入口。
- **信息密度**：单页共 3236px 高的内容（桌面视口），分为吸顶玻璃 Header、Hero、最新新闻卡片、四行产品抽屉、四张技术专题卡与页脚。信息密度中等，通过大留白（模块底部间距 168px）与大圆角表面控制视觉节奏。
- **设计关键词**：暖白底色、玻璃质感、20px 圆角、商汤红点缀、卡片式编辑风。

## Do's and Don'ts

- **Do** 使用 `#f02e27` 作为商汤红 / 主要 CTA 底色；`:root` 的 `--red` 与 `--red-strong` 同值。
- **Do** 使用 `#fbfaf7` 作为整站底色；不要替换成纯白 `#ffffff`。白仅用于技术卡与产品抽屉展开面板等 surface。
- **Do** 使用暖灰 `#111827` 与纯黑 `#000000` 两档主文本色区分「导航 / 内容」（`#111827`）与「Hero 标题 / 分区标题 / 页面文字」（`#000000`）。
- **Do** 使用 `#667085`（`--muted`）作为副标题、描述、未激活子导航文字；`#7a7a7a` 用于下拉分组小标题；`#9f9f9f` 用于页脚版权。
- **Do** 保留 20px 大圆角作为大卡片（新闻特色、技术卡、产品展开面板）语言，8px 小圆角作为按钮 / chip 语言；不要在卡片上叠加描边。
- **Do** 保留玻璃质感表面：头部使用 `rgba(255, 255, 255, 0.28)` + `backdrop-filter: blur(34px) saturate(1.16)`；产品展开面板使用 `rgba(255, 255, 255, 0.2)` + 内联 `linear-gradient` + `--glass-border` 描边。
- **Do** 使用双层阴影：技术卡 `rgba(38, 48, 72, 0.02) 0 2px 6px, rgba(255, 255, 255, 0.92) 0 1px 0 inset`，产品展开面板 `0 3px 10px rgba(38, 48, 72, 0.04)`。不要给主要 CTA 按钮加阴影。
- **Do** 使用 `--module-gap: clamp(88px, 13.125vw, 168px)` 与 `--page-max: 1180px` 控制模块间距与内容最大宽度，桌面 1280 下分别解析为 168px 与 50px 侧边距。
- **Do** 保留 fluid 字号策略：`--font-root-fluid: clamp(14px, 0.8125rem + 0.35vw, 16px)`，移动 390 下 body 字号自动降到 14.365px，rem/em 元素等比缩小。
- **Don't** 把 body 字体栈首位 `Open Sans` 说成所有平台最终安装的字体；本次环境为 Playwright Headless Chromium on macOS，未通过字体枚举验证；中文字形实际命中 `PingFang SC` / `Source Han Sans SC` / `思源黑体` 之一。
- **Don't** 把 `:root` 声明的 `--serif-title-font: Lora, Georgia, ...` 推断为正在使用的衬线标题字体；首页所有标题实际使用正文栈。
- **Don't** 把未观察到的 hover / focus / active 状态、产品抽屉展开动画、语言切换行为、Hero 渐变与标题文字的关系、以及英文版或其他地区页面的组件差异补写为规范。
- **Don't** 用 `word-break: break-all`、`line-break: strict` 或 `text-wrap: balance` 等通用中文字体优化；页面 computed 全部为 `auto / normal`，未启用此类规则。
- **Accessibility**：Playwright 快照显示主要导航、CTA 与内容均可被浏览器读取；未做键盘遍历、对比度或触控目标尺寸验证。移动视口下 `body.scrollWidth` 为 408px（宽于 390px 视口 18px），未定位到具体元素，也不断言溢出策略。
- **对比度说明**：主要 CTA 红底（`#f02e27`）配纯白文字（`#ffffff`）的对比度约为 4.10:1，低于 WCAG AA 4.5:1 门槛，但保留原站设计——商汤红是品牌主色，全站主要 CTA（顶部「产品咨询」、新闻「了解更多」、`.primary-button--arrow` 等）一致使用该组合，未在预览中改写。
