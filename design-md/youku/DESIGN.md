# DESIGN.md — 优酷 Youku

**来源 URL**：https://www.youku.com/（跳转至 `https://www.youku.com/ku/webhome`）  
**采集范围**：优酷官网首页（Web 首页）单页；桌面 1280×720 与移动 390×844；未登录状态；页面标题「优酷-热门独播剧集综艺电影在线观看-为好内容全力以赴」。  
**采集日期**：2026-09-30  
**证据环境**：Playwright Headless Chromium（playwright-cli），macOS。

## Overview

- **视觉气质**：接近纯黑的暗色舞台底色（`#151618`）+ 白色文字 + 半透明玻璃表面（`rgba(255,255,255,0.04–0.08)`），形成电影 / 视频网站的典型"影院"氛围；会员 / VIP 相关的金色（`#ffde9c`、`#ffdd9a`）与暗红（`#ff4f34`、`#501618`）负责促销与强调，其余内容以白色不同透明度形成层次。
- **目标用户 / 场景**：面向公众的视频内容门户，聚合剧集、动漫、电影、综艺、短剧、纪录片、体育、人文等栏目；顶部引导登录 + 会员开通，中部按热度榜 / 独播榜分组展示节目封面卡片。
- **信息密度**：桌面 2412px 页面高度，采用 76px 顶部条 + 176px 左侧边导航 + 主内容横向卡片列表（每行 119.5 / 163.33 宽卡片，行高 159.33 / 271.75）。卡片不描边、不投影、圆角为 0，靠深色底 + 白字 + 标签色区分内容类型。信息密度高但视觉安静。
- **设计关键词**：暗色影院、玻璃表面、金色 VIP、横向卡片行、极简无描边。

## Typography

### 3.1 中文字体与字形

- **简体中文**：`html` 与 `body` 的 computed `font-family` 为 `"pingfang SC", "Microsoft YaHei", 微软雅黑, helvetica, arial, verdana, tahoma, sans-serif`。栈首位是 `pingfang SC`（注意此处大小写为小写 s C，作为 CSS 声明原样保留），中文字形主要回退到 `Microsoft YaHei` / `微软雅黑`，再兜底到 `helvetica, arial, verdana, tahoma, sans-serif`。部分组件（`.pack_title_vhB7u`、`.pack_subtitle_1HHha`、`.newSummaryLeftText_22TVB`）单独覆盖为 `"PingFang SC"`（大写 SC）。
- **繁体中文**：本次访问未见 `zh-TW` / `zh-HK` 入口，未见繁体渲染证据。
- **实际渲染字体**：本次环境为 Playwright Headless Chromium on macOS。macOS 上 `PingFang SC` 与 `pingfang SC`（不区分大小写的字体名匹配由浏览器决定是否接受，未验证）都会命中；`Microsoft YaHei` / `微软雅黑` 在 Linux / Windows 上会命中。未枚举系统字体，未做字体回退验证。
- **缺字回退**：未确认具体字形回退行为；不要断言最终渲染字体。
- **数字专用字体**：会员价格高亮 `.crmusercenter_highlight` 使用 `QY_Digital-SemiBold`（20px / 500 / 20px / `#ff4f34`）——这是一条自托管 / 内嵌的西文数字字体，仅在促销数字（如 "9.9"）处激活。

## Do's and Don'ts

- **Do** 使用 `#151618` 作为整站底色；不要替换成纯黑 `#000000` 或任何浅色。
- **Do** 使用白色透明度阶梯（`#ffffff`、`rgba(255,255,255,0.8)`、`0.6`、`0.4`）建立信息层级：白 → 80% → 60% → 40%。
- **Do** 用金色（`#ffde9c`、`#ffdd9a`）专用于 VIP 相关；用暗红（`#ff4f34`）专用于会员价格高亮数字。
- **Do** 玻璃表面统一走 `rgba(255,255,255,0.04–0.08)` 的极弱半透明白；不要引入纯色白色 surface。
- **Do** 卡片角标统一 `rgba(24, 25, 27, 0.6)` 底 + `border-radius: 4px` + `padding: 0 6`；通过颜色区分含义（白 / 白 60% / 金）。
- **Do** 卡片本体保持 `border-radius: 0`、`box-shadow: none`、`border: 0`；不要在封面卡片上加圆角或阴影。
- **Do** 胶囊类按钮使用强圆角（18px 登录 / 30px VIP），配合极弱描边；不要给胶囊去掉描边。
- **Do** 促销 CTA「立即开通」保留 `color / border-color: #501618` 的暗红描边组合；该按钮依赖其父容器的渐变 / 图片背景，独立使用时视觉不成立，需要在预览中标注其上下文。
- **Do** 保留 `QY_Digital-SemiBold` 用于会员价格高亮数字（"9.9"）；这是本次唯一观察到的自托管字体声明。
- **Don't** 把 `body` 声明的 `font-family` 首位 `"pingfang SC"`（小写 s C）改写为 `"PingFang SC"` 后再声称页面原样；两种大小写在页面中都出现，`pingfang SC` 用于 body 与大多数组件，`PingFang SC` 用于部分卡片标题。
- **Don't** 推断 hover / focus / active / loading 状态样式；本次采集未模拟任何交互态。
- **Don't** 使用 `word-break: break-all`、`line-break: strict`、`text-wrap: balance` 等通用中文字体优化；页面 computed 全部为 `auto / normal`。
- **Don't** 把 `body` computed 的 `color: rgb(0, 0, 0)` 说成全站文本色；这是继承默认，页面实际文本色由子元素显式声明为白色 / 白-XX。
- **Accessibility**：Playwright 快照显示主要导航、卡片、按钮均可被浏览器读取；未做键盘遍历、对比度或触控目标尺寸验证。VIP 胶囊金色 `#ffde9c` 在 `rgba(255,255,255,0.08)` 玻璃底上视觉对比度较高；卡片副标题 `rgba(255,255,255,0.4)` 在深色底上对比度较低，未做数值化 AA 校验。
- **对比度说明**：卡片副标题 `rgba(255,255,255,0.4)` 与"更新话数"标签 `rgba(255,255,255,0.8)` 都直接叠在深色封面图上，实际对比度取决于封面图本身；本次未做像素级对比度校验。
- **保留的 lint 警告**：`design.md lint` 对本页 4 个组件（`.pill-vip`、`.pill-login`、`.promo-cta`、`.view-all`）报 contrast-ratio 警告。这些组件的 `backgroundColor` 都是半透明玻璃色（`rgba(255,255,255,0.04–0.08)`）或透明，实际视觉效果叠在整站底色 `#151618` 或卡片封面上才成立；lint 工具无法感知这一合成背景，因此这些警告属于工具局限而非设计缺陷。此处保留原样式，不修改以匹配原站；同时保留玻璃表面家族是本次提取的证据。
